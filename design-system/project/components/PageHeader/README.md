Every page opens with breadcrumbs, a condensed 28px title over a hairline, and optional subtitle and actions. Gutters are 32px on desktop, 16px under 860px.

`.ptitle h1.brand` (Nexus Blue, uppercase) is for the product home only. Page bodies go in `.pbody`. Use `.section-h` for in-page section headings: small, condensed, uppercase, `text-2`.
