A segmented control picks one of a few views or modes. The track is `surface-3`; the chosen option is raised on `surface` with a 2px `accent` underline and bold text.

Use `.seg` with `<button>` children and mark the active one with `aria-pressed="true"` (or `.on`). Keep to two to five short options. For a single on/off setting that applies immediately use a Switch (`.switch`, shown here too); for navigation between pages use the side bar, not a segmented control.
