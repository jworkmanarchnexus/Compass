Chips label a status or category in a few characters; counts (`.cnt`) badge a number; avatars (`.avatar`) show a person.

One meaning per color: `blue` is selected or informational, `ok` is done, `warn` needs attention, `crit` is wrong or blocked. Always put the word in the chip so color is never the only signal. Chips are 22px tall pills in condensed bold.

**Don't** add new chip colors for decoration; add a status first.
