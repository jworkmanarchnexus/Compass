A dialog interrupts for one decision or one short form. `scrim` behind it, `surface` card with `r4` radius and `shadow-2`, 480px wide (`wide` 680, `xwide` 1040).

Structure: `h2` title, `.dlg-body`, `.dlg-act` footer with Cancel on the left of the primary. Escape and the scrim dismiss unless data would be lost. Open focus on the first field or the safest button. Never stack dialogs.
