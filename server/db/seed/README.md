# Seed data

Everything here is made up (shapes follow the handoff mockup). Locally these CSVs stand in for two things that production replaces:

- `employees.csv`, `projects.csv`: the nightly copy from Vantagepoint (`EMMain`, `PR`). Column names follow the VP fields the validated SQL uses. **The project number format (`2024-0207`) is the mockup's, not a confirmed Vantagepoint format** (handoff open question about keys).
- `users.csv`: the People table. In production sign-in is the company login and Josh sets roles in Admin. `Employee` links a PIC to their Vantagepoint employee code.

`npm run seed` resets the local database to this data.

- `ledger.csv`, `overhead.csv`: the made-up stand-in for the Vantagepoint pull (monthly billed, labor, expenses and overhead rates per project). Generated by `tools/make-seed-ledger.js` so the September 2026 run matches the mockup. See `server/vp-local.js`.
- `plan_stories.json`: made-up plan logs for the demo, written around the mockup's story and its date (Oct 7, 2026). Run with `COMPASS_TODAY=2026-10-07` to see exactly the mockup's statuses.
- `pipeline_pursuits.csv`, `pipeline_forecast.csv`, `pipeline_projects.csv`: the made-up stand-in for the pipeline pull: eight Monday snapshots (Aug 17 to Oct 5, 2026) of pursuits and contracted forecast, and the project numbers that exist. Generated by `tools/make-seed-pipeline.js` to match the mockup. `npm run seed` takes the eight snapshots through the same code the Monday job uses.
- `bd_forecast_months.csv`, `bd_mwip_months.csv`: each forecast project's and pursuit's amount split across the remaining months (and pursuit names), for the Marketing Report's drill-downs. Generated by `tools/make-seed-bd-months.js` from the totals in `bd_forecast.csv` and `bd_mwip.csv`, which do not change.
